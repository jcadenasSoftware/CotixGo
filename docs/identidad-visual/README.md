# Identidad visual CotixGo

Esta carpeta reúne recursos visuales aprobados y referencias del trabajo de identidad.

## Logos

Los archivos con sufijo `referencia` sirven para inspección y composición visual. Los PNG disponibles tienen fondo blanco; no son todavía exportaciones transparentes optimizadas para producción. El SVG del símbolo es un vector de referencia y conserva un fondo blanco.

## Referencias

Incluye la paleta y las láminas de versiones monocromáticas para consultar sus colores y apariencia. No usar las láminas completas como imágenes de interfaz.

Para recursos finales de la app, exportar desde Canva o preparar versiones transparentes y revisar su escala antes de integrarlos en `android/app/src/main/res`.
